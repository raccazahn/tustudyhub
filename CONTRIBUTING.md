# Contributing to TuStudyHub

This is a graded team project. Work must be traceable, reviewed, tested, and understood by the contributor.

## Workflow
1. Read the root README and the relevant document.
2. Create/select a GitHub Issue with an owner, scope and acceptance criteria.
3. Create a branch, e.g. `docs/interview-guide`, `feat/paper-upload`, `fix/verification-status` or `test/paper-api`.
4. Do not commit directly to `main`.
5. Open a focused pull request linked to the issue. Obtain approval from at least one other team member before merging.
6. Use descriptive commit messages such as `docs: add interview guide`.
7. Update documentation when decisions or behaviour change.

## Before opening a PR
- [ ] Meets the issue's acceptance criteria.
- [ ] Relevant tests/checks were run and results recorded.
- [ ] Relevant documentation updated.
- [ ] No secrets, real student data, unauthorized exam files or copyrighted materials included.
- [ ] AI assistance disclosed if used.
- [ ] Contributor can explain the change and decisions.

## AI-assisted work
AI may assist with planning, writing, coding and debugging. Contributors remain responsible for reviewing, testing and understanding submissions. Never provide credentials, API keys or real student data to AI tools. Describe in the PR what AI assisted with and what you personally reviewed/tested.

## Definition of done
Acceptance criteria met, tests/checks recorded, relevant docs updated, and PR reviewed and merged. Verify deployment when required by the week's deliverable.
