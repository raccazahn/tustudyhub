# Mobile-first Wireframes and PWA Shell

**Owner:** UX / Frontend role (assign in team plan)  
**Week 2 deliverable:** mobile-first wireframes and PWA shell.

## Minimum screens to sketch
- [ ] Public landing / sign-in entry.
- [ ] Registration and login.
- [ ] Student home and course/document search.
- [ ] Document results filtered by course and type.
- [ ] Document detail/download and verification status.
- [ ] Upload form with type, course, year and other required metadata.
- [ ] Lecturer/moderator review and approval screen.
- [ ] Quiz list, quiz attempt and score result.
- [ ] Public QR verification page showing Verified or Revoked.

## PWA shell checklist
- [ ] Responsive mobile-first layout.
- [ ] Web app manifest and suitable icons.
- [ ] Service worker and installability checked.
- [ ] Lightweight assets and readable typography/contrast.
- [ ] Test on a phone or mobile browser and record evidence.

Attach wireframe images or links below. Do not claim the PWA is complete until installability is tested.
