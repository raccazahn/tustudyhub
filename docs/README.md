# Documentation Index

- `planning/` — charter, team roles, backlog, weekly and final checklists.
- `requirements/` — requirements, user stories and interview guide.
- `design/` — technology decisions, SDD, architecture and data model.
- `api/` — API resource and endpoint contract draft.
- `operations/` — infrastructure and deployment/recovery guides.
- `security/` — initial threat register.
- `testing/` — QA strategy and acceptance scenarios.
- `contributing/` — responsible AI-assisted work.

Label assumptions and pending decisions clearly. Do not invent interview findings, team assignments, prices or deployment facts.
