# Responsible AI-Assisted Work

The concept paper encourages Claude Code and other AI tools, but students remain responsible for submitted work.
- Review and test generated code, text and diagrams.
- Do not submit work or decisions you cannot explain in the oral defence.
- Never share passwords, API keys, real student data or sensitive production details with AI tools.
- Disclose AI assistance in the PR: tool used, task assisted, and what you personally reviewed/tested.
- Verify claims against project requirements and appropriate documentation.
